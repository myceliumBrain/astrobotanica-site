# Regras deste repositório (astrobotanica.com.br)

- O site está no ar via GitHub Pages. NUNCA faça commit, push ou merge na branch main sem eu pedir explicitamente.
- Todo trabalho acontece na branch "migracao-ssg".
- NUNCA apague, mova ou altere o arquivo CNAME. Ele deve existir também na saída do build.
- NUNCA altere configurações do GitHub (Pages, Actions, domínio) — eu faço isso manualmente.
- Antes de apagar qualquer arquivo, liste o que será apagado e espere minha confirmação.
- Toda URL que existe hoje no site deve continuar funcionando (mesma URL ou redirecionamento).
- Depois de cada mudança, rode o build e confirme que termina sem erros antes de fazer commit.
- Commits pequenos e descritivos, em português.
- Conteúdo publicado (textos das notícias) não pode ser reescrito, apenas migrado de formato.
